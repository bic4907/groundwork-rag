01 / RETRIEVAL

Evidence recall

질문에 필요한 정답 근거 문장 중 검색 결과에 포함된 비율입니다. 여러 문서를 연결하는 질문에는 모든 근거를 찾았는지도 함께 봅니다.

02 / ANSWER

Token F1 ≠ 정답성

정답과 답변의 단어 중복입니다. 표현이 달라도 맞는 요약을 낮게 평가할 수 있습니다. 의미적 정답성은 별도 Judge와 사람 검토가 필요합니다.

03 / CITATIONS

인용의 존재와 타당성

인용 ID와 원문 구절이 실제로 있는지 자동 검증합니다. 그 구절이 주장을 뒷받침하는지는 Citation Support로 별도 평가합니다.

04 / ABSTENTION

모를 때 답하지 않기

답이 없는 질문에서 보류했는지, 답할 수 있는 질문까지 보류하지는 않았는지 함께 측정합니다. 호출 오류는 성공한 보류로 계산하지 않습니다.

05 / REPRODUCIBILITY

실행의 흔적

모델 식별자, 데이터·프롬프트 해시, 설정, seed, 검색 근거, 응답을 저장합니다. 외부 API는 동일한 seed에서도 결과가 달라질 수 있습니다.

06 / LIMITATIONS

작은 실험의 범위
